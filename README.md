# AI & Machine Learning Using Python

A combined Artificial Intelligence demonstration project developed using Python. This project demonstrates three major AI concepts through an interactive Gradio web application.

## 🚀 Project Overview

The application combines:

1. **Machine Learning** – Student Pass/Fail Prediction
2. **Deep Learning** – Handwritten Digit Recognition
3. **Generative AI** – AI Image Captioning

The project provides a simple interface where users can interact with all three applications through separate tabs.

## 🧠 Features

### 1. Machine Learning

**Student Pass/Fail Prediction**

A Logistic Regression model predicts whether a student will pass or fail based on the number of study hours.

* Algorithm: Logistic Regression
* Input: Study hours
* Output: PASS / FAIL

### 2. Deep Learning

**Handwritten Digit Recognition**

A neural network trained using the MNIST dataset recognizes handwritten digits from uploaded images.

* Dataset: MNIST
* Framework: TensorFlow
* Input: Handwritten digit image
* Output: Recognized digit

### 3. Generative AI

**AI Image Captioning**

A BLIP image captioning model generates a text description for an uploaded image.

* Model: BLIP
* Framework: Transformers + PyTorch
* Input: Image
* Output: AI-generated caption

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Mjaswanthreddy/AI-Machine-Learning-Demonstration.git
```

Move into the project directory:

```bash
cd AI-Machine-Learning-Demonstration
```

Install the required Python libraries:

```bash
pip install -r requirements.txt
```

## ▶️ Run the Application

Run the Python program:

```bash
python src/ai_demonstration.py
```

The Gradio application will launch and provide an interactive interface.
